## 独立真实 Core 主程序验证

独立执行者使用冻结的 Core 与 `model_process` 二进制，通过运行时 TOML 启动真实 OS 进程，经 TCP HTTP／SSE 连接独占 PostgreSQL 18.6。账号、资金和上游供应商响应均为合成测试数据，上游位于本地回环网络。
