本批次修复首页与公共导航的配置读取，不代表整个前端或业务系统已经验收完成。

## 已实现

- 保留显式配置的站点名称和 Logo，包括历史名称和图片路径；空配置仍使用默认值，图片加载失败仍有回退。

- Core 导航持久化已接入设置接口和公开状态接口，新增第 47 个组件及独立 46→47 离线升级。公开服务地址来自当前启动配置，不能通过通用设置接口覆盖。具体合同与本次验证见 [导航配置升级](navigation-options-upgrade.md)。
