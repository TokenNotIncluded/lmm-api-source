# LMM API 退款政策

版本 2.1 · 公告日期 {{notice_date}} · 變更生效日期 {{effective_date}}

本頁列出[服務條款](/user-agreement)第 7 條的退款規則。服務在美國營運，僅向在中國大陸以外地點使用的使用者開放。本次更新保留既有訂單產生的退款和帳單異議權利。如已有訂單、帳戶餘額或爭議，仍可透過 [support@lmm.best](mailto:support@lmm.best) 聯絡我們；查帳、申訴和法定權利不以能否繼續使用服務為前提。

### 7.1 總體原則

由於本服務屬於付款後即時交付的數位服務，**已消耗或已部分消耗的儲值餘額原則上不支援退款**。贈送、促銷、測試、返利或補償額度不支援兌換現金或退款。適用法律另有強制規定的，從其規定。

### 7.2 可申請退款的情形

符合下列任一情形的，您可以申請退款：

1. **7 日內完全未使用：** 自儲值成功之日起 7 個自然日內提出申請，且該筆儲值對應的餘額未發生任何使用、轉讓或兌換，可申請該筆儲值全額退款。
2. **重複扣款：** 因系統或支付處理錯誤造成同一訂單重複扣款，經核實後退還重複收取的金額。
3. **確認的計費錯誤：** 因平臺結算錯誤造成多扣款或錯誤扣款，經核實後退還錯誤收取的金額。
4. **付款成功但服務未交付：** 付款已完成但因平臺原因未入帳，且我們無法在合理期限內補發對應餘額或權益，可申請退款。
5. **平臺原因停止服務：** 因我們停止服務且並非由於您違約造成的，可退還依法應退的未使用付費餘額，或由雙方協商提供等值補償。
6. **法定退款權利：** 適用法律規定您享有撤銷、退款或其他不可放棄的消費者權利。

### 7.3 不予退款的情形

除第 7.2 條或適用法律另有規定外，下列情形不予退款：

1. 儲值餘額已經使用或部分使用；
2. 超過 7 個自然日後因個人原因提出的未使用餘額退款；
3. 因未閱讀定價頁面、選錯模型、配置錯誤、遺失憑據或帳戶被他人使用產生的正常用量；
4. 贈送、促銷、測試、返利、兌換或補償額度；
5. 因欺詐、違法活動、濫用服務或其他嚴重違反本條款的行為導致帳戶被暫停或終止；
6. 第三方模型已正常提供並完成結算，但其輸出未達到您的主觀預期。

### 7.4 退款申請與處理

請使用註冊信箱傳送退款申請至 [support@lmm.best](mailto:support@lmm.best)，郵件標題註明「退款申請」，並提供：

- 註冊信箱；
- 訂單號或交易 ID；
- 儲值時間和金額；
- 退款原因及必要的證明材料。

我們通常會在 2 個工作日內確認收到，在 5 個工作日內完成稽核或告知進一步處理進度。獲批退款原則上在稽核完成後 5 個工作日內提交至原支付渠道；實際入帳時間通常為 5–10 個工作日，具體取決於支付機構、髮卡行或銀行處理時間。

退款完成後，相應餘額或權益將被扣回。為防止重複結算，在退款申請處理期間，我們可以暫時凍結與申請金額對應的未使用餘額。
