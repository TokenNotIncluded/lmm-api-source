## 2. 我们处理的信息

为提供服务，我们可能处理：

- 账户信息，例如用户名、邮箱以及您选择绑定的登录标识；
- 认证与安全信息，例如密码摘要、API 密钥（通过访问控制保护，并在管理界面默认掩码展示）、登录时间、IP 地址、设备和浏览器信息；
- 使用与计费信息，例如所用模型、请求时间、令牌或请求用量、余额变动、订单和错误记录；
- 请求内容，例如您主动提交的提示词、文件以及模型生成结果。此类内容仅在转发请求、返回结果、排障、安全审计或履行法律义务所必需的范围内处理；
- 外部工具连接信息，例如您主动登记的服务器地址、安装标识、OAuth 授权范围及其令牌，或您为该服务提供的专用密钥。平台使用这些信息建立您选择的连接、读取工具清单和处理获准调用。调用工具时还会处理此次调用的参数和返回结果；
- 您主动提供给客服的通信内容。

请勿提交无权处理的个人信息、国家秘密或其他法律禁止处理的内容。

## 3. 处理目的与方式

我们通过自动化系统和必要的人工支持处理信息，用于创建和保护账户、鉴权、转发模型请求、计算费用、提供客服、排查故障、防止欺诈滥用、改进稳定性以及履行法定义务。我们不会出售您的个人信息，也不会将您的请求内容用于训练面向公众的模型。

## 4. 保存期限

我们仅在实现上述目的所必需的期间保存信息：账户资料通常在账户存续期间保存；使用、计费和安全记录按照排障、争议处理、安全审计及法定义务所需期限保存；客服记录保存至问题处理完成及合理的争议期结束。账户注销后，我们会在合理期限内删除或匿名化相关信息，但法律要求保存或处理争议、安全事件所必需的信息除外。

## 5. 委托处理、共享与跨境传输

为完成您选择的模型请求，我们会向对应的模型或基础设施提供方传输必要的请求内容和技术信息；支付场景下，订单所需信息可能提供给支付服务商。如果您连接外部工具，指定的工具服务器会收到执行您所选操作所需的认证信息或令牌、查询和调用参数。平台不会把您的本站登录令牌或钱包凭据发给工具提供方。为授权、故障排查、交付和计费核对，平台可能保存与账户及授权关联的调用参数、状态、用量、报价和返回结果。当提供方支持时，断开连接会申请撤销其授权；提供方实际撤销的时间由其系统决定。如有设备中继流量服务且您选择购买，平台会记录账户与订单标识、账期、购买的字节额度、报价、交易状态和扣款或发放回执。平台使用这些信息核对付款和流量到账；发放服务会收到所需的账户和订单标识、账期与额度。模型、身份验证、支付或工具提供方可能在其他地点处理其收到的数据，具体取决于您选择的提供方和服务。我们仅为提供所选服务进行必要传输，并要求相关方按照适用规则保护信息。具体模型及计费条件可在[定价页面](/pricing)查看。

## 6. Cookie 与本地存储

网站可能使用 Cookie 或浏览器本地存储来保持登录状态、记住界面偏好、保存安全状态并改善使用体验。禁用必要存储可能导致登录或部分功能无法使用。

## 7. 您的权利

您可以依法请求查阅、复制、更正、补充或删除个人信息，撤回基于同意的处理，申请注销账户，或要求说明处理规则。请使用注册邮箱发送请求至 [support@lmm.best](mailto:support@lmm.best)。为保护账户安全，我们可能先核验您的身份，并在适用法律要求的期限内答复。请勿在邮件中附上密码、完整 API 密钥、OAuth 令牌或完整支付卡号。

## 8. 安全措施

我们采用访问控制、权限隔离、传输保护、日志审计和系统加固等措施降低信息被未经授权访问、泄露、篡改或丢失的风险。如发生可能影响您权益的安全事件，我们会采取补救措施，并按适用法律履行通知或报告义务。

## 9. 未成年人

本服务主要面向具备完全民事行为能力的用户。未成年人应在监护人指导和同意下使用，不应自行提交敏感个人信息或进行付费。

## 10. 政策更新与联系

我们可能因服务或法律要求更新本政策，并在网站公示生效日期。影响既有用户的重大变更遵循[服务条款](/user-agreement)第 14 条的提前通知安排。有关隐私、投诉或权利请求，请联系 [support@lmm.best](mailto:support@lmm.best)。


## 内容安全审查补充说明

内置 AI 助手与 API 安全审计提供默认关闭的 OpenAI Moderation 内容审查功能。管理员可以分别启用两项功能，并明确配置适用的账号分组；未配置的分组保持关闭。

在启用的范围内，实际提取的本次待审文字经必要的最小化和脱敏处理后会发送给 OpenAI 官方 Moderation 接口，用于后台内容分类。API 仅提取已识别协议中最后一条用户消息的文字；内置助手提取本次用户输入，并将助手回复单独处理，不提交整个请求 JSON、全部历史对话、系统提示、工具定义或工具结果。未知请求结构不强行提取。文字仍可能含有您主动提交的个人信息或其他敏感内容；请勿提交无权处理的个人资料或秘密。当前功能仅支持文字，不覆盖图片、音频、视频或文件二进制。支持长度内的长文本分块审查，全部批次成功后才处理分类结果；超限或未实际审查的内容不作完整审查结论。

转交人工客服的聊天沿用现有私密客服流程，不经过 OpenAI 内容审查，也不作为该功能的 AI 输入或模型输出记录。

平台通过内部持久化任务队列处理审查，必要的分类、任务状态、通知、余额变动和风险统计记录用于安全管理、执行已公示规则及处理复核。相关信息的保存期限、访问控制、跨境处理和权利请求继续适用本隐私政策。用户输入与模型输出分别处理；仅已完成审查的用户输入违规统计纳入用户风险分，模型输出不增加用户风险分。风险分采用启发式管理阈值，并与既有钱包风险分取较高值，不代表违法概率或分类可信度；已审查请求数只是计数。金额按最小账本单位向下取整，实际扣款不超过配置金额及可用正余额，不足一个账本单位仅提醒，不产生新欠款。

OpenAI 的处理遵循其适用条款和[官方数据控制说明](https://developers.openai.com/api/docs/guides/your-data)。本补充不承诺平台或第三方在所有安全、法律场景下均不保存任何信息。

具体功能边界见[安全审查说明](/legal/safety-review.html)，当前分组模式及类别金额见[公开安全规则](/security)。您可通过站内支持或 support@lmm.best 对审查记录、风险统计与余额处理申请人工复核；请勿发送密码或完整 API Key。
